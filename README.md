# Pulseboard

Pulseboard is a responsive SaaS landing page created for the Sankar Group Front-End Development Internship assignment. It presents a fictional customer-intelligence product that helps product teams turn scattered feedback and analytics into focused growth actions.

## Run locally

No build step or package installation is required.

1. Clone or download this repository.
2. Open `index.html` in a browser, or serve the folder with `python -m http.server 8000`.
3. Visit `http://localhost:8000`.

## Technologies

- Semantic HTML5
- CSS3 with responsive breakpoints and custom SVG chart illustration
- Vanilla JavaScript for the mobile menu and validated demo request form
- Google Fonts (DM Sans and Space Grotesk)

## Design choices and challenges

The visual direction pairs a warm off-white canvas with purple, orange, and mint accents to make the product feel clear and optimistic. A dashboard preview gives the hero an immediate product context without relying on third-party imagery. Content is organized into a simple signal-to-action story so the page remains easy to scan. The responsive layout changes from a two-column desktop composition to a single-column mobile flow. The form validates email input on the client and provides a visible success state without requiring a backend. All navigation links use anchored sections for predictable movement through the page.
